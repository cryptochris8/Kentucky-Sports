# 07 — Gamification and Community

## Goal

Create a fun fan layer that keeps users opening the app before, during, and after games.

## Core loops

### Daily loop
1. Open app.
2. See Pulse card.
3. Vote in poll.
4. Make one prediction.
5. Earn XP/streak.
6. Read stat card or news link.

### Gameday loop
1. Open Gameday HQ.
2. Submit predictions.
3. Check live fan confidence.
4. React to key moments.
5. Compare stats.
6. See postgame scoring.
7. Earn badge/cards.

### Season loop
1. Build prediction record.
2. Complete badge sets.
3. Climb leaderboard.
4. Unlock profile cosmetics.
5. Follow team/high-school pages.

## XP system

### XP events

| Action | XP |
|---|---:|
| Daily app open | 5 |
| Vote poll | 5 |
| Submit prediction | 10 |
| Correct prediction | 20 |
| Exact score bonus | 100 |
| Comment approved/upvoted | 5 |
| Game check-in | 25 |
| Watch-party check-in | 25 |
| Read stat explainer | 5 |
| Follow high school/team | 5 |

Add anti-abuse limits:
- daily cap for low-value actions
- one prediction per question per user
- one check-in per venue/game
- moderation for posts/comments

## Digital collectible cards

MVP can use simple badge cards, not NFTs.

Card types:
- game cards
- rivalry cards
- milestone cards
- prediction streak cards
- high school spotlight cards
- historical trivia cards

Rarity:
- common
- rare
- epic
- legendary

Do not use NCAA athlete likenesses for monetized collectibles without rights. Use abstract designs, numbers, helmets/balls/shapes, venue-inspired art, and text-based achievements.

## Community design

### MVP community surfaces
- game thread comments
- poll discussions
- hot take card
- reactions
- moderated posts

### No direct messaging in MVP
Avoid direct messaging at launch, especially because the app may include high school sports. Direct messaging introduces moderation and minor-safety complexity.

### Moderation
- profanity filter
- report post/comment
- role-based moderators
- hidden/pending/visible statuses
- ban/suspend user
- audit log

## Notifications

Smart notifications:
- morning pulse
- game starting soon
- prediction closing soon
- final score and prediction results
- badge earned
- recruiting/high-school alert if followed
- watch party nearby, if user opts in

Avoid spam:
- user controls by sport and notification type
- quiet hours
- no more than one generic news alert per day unless major event
